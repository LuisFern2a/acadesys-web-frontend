# Recursos gráficos provisionales

El export de texto `FRONTEND(7).md` no incluía los binarios `hero.png` ni `acadesys-mark-teal.png`, aunque el código los importa. Para que el árbol extraído no tenga imports rotos, se han añadido dos gráficos provisionales creados para desarrollo local. **No son los originales del repositorio ni deben reemplazar la identidad visual aprobada.** Antes de integrar o desplegar, sustituirlos por los dos archivos auténticos de `frontend/src/assets/` del repositorio del equipo, conservando esos nombres.
